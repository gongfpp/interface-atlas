## 🚀 快速开始（3 分钟）

### 最快路径

```bash
# 1. 新建 Remotion 项目
npx create-video@latest atlas-promo && cd atlas-promo

# 2. 复制核心实现代码
cp [项目路径]/AtlasPromo.core.tsx ./src/AtlasPromo.tsx

# 3. 编写 src/index.ts
cat > src/index.ts << 'EOF'
import { registerRoot } from 'remotion';
import { Composition } from 'remotion';
import { AtlasPromo } from './AtlasPromo';

registerRoot(() => (
  <Composition
    id="AtlasPromo"
    component={AtlasPromo}
    durationInFrames={900}
    fps={30}
    width={1080}
    height={1920}
    defaultProps={{ bgm: true }}
  />
));
EOF

# 4. 本地预览
npm run dev

# 5. 渲染成片
npx remotion render src/index.ts AtlasPromo out/atlas-promo.mp4
```

**完成**！你现在有了一个可工作的 30 秒抖音宣传片。

## 📞 常见问题速解

**Q: 代码能直接跑吗？**
A: 是的。只需复制 `AtlasPromo.core.tsx` 到标准 Remotion 项目即可编译、预览和渲染。

**Q: 需要立即准备音乐吗？**
A: 不需要。代码中有 `bgm: boolean` 开关，可先用纯 SFX 版本验证效果，后期配乐。

**Q: 能改时长吗？**
A: 可以，但需要按比例调整所有镜头帧数。建议先用当前 30s 验证质量。

**Q: 渲染要多久？**
A: 约 2-5 分钟（1080×1920@30fps 30 秒）。

**Q: 能改成其他平台吗？**
A: 可以。修改 Composition 宽高参数即可生成小红书 (1080×1440) 或 B 站 (1920×1080) 版本。
