# 样板与操作动效迭代 · 2026-10-28

本轮继续打磨已有 Bauhaus、Hand-drawn、Retro-futurism 三种样板，并按用户要求补齐按钮点击反馈与标题栏不同功能页之间的动画。保留品牌、文案、业务操作、中英版本、静态封面与整页同源，以及样板状态仅存于当前文档的边界；不增加业务功能、依赖或解释性标签。没有批准降低体验目标的技术折中。

## 可观察的体验目标

| 核心目标 | 实现与验收条件 |
| --- | --- |
| 点击后有可见反馈，位置稳定 | 鼠标与键盘触发同一短亮度反馈；不缩放点击区域、不改变业务执行顺序；动态生成的按钮也覆盖 |
| 标题栏换页连续 | 同源页面使用原生跨文档过渡，标题栏保持稳定，栏目标记移动，旧正文退出后新正文进入；八个功能页、返回与语言切换均能继续操作 |
| 不支持原生过渡的浏览器也有反馈 | 普通站内链接先做 140ms 退出，再导航并进入；连续点击以最后目标为准，同页锚点取消旧的延迟导航；返回后不残留透明度 |
| 样板内导航不再突然跳动 | 用户主动导航采用平滑滚动与面板入场；业务状态立即更新，快速切换不会回写旧面板 |
| 弹窗关闭可见，焦点可恢复 | 样板弹窗保持原生模态边界至 160ms 退出结束，随后关闭并归还焦点；站点搜索弹窗同样有退出反馈 |
| 手机预览与模式切换连续 | 预览宽度平滑调整，重新加载完成后淡入；样板文档不启用跨文档快照，避免调整 iframe 宽度时中断原生过渡 |
| 减少动态偏好有效 | 关闭新增位移、淡入、点击与跨页动画，保留导航、表单、焦点和状态反馈；动效播放器的无动画／暂停区不被公共点击效果覆盖 |

原生跨文档能力依据 [MDN View Transition API](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API/Using) 与 [@view-transition](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@view-transition) 实现。保留整页导航及脚本初始化，不引入客户端路由。浏览器差异通过能力检测处理；代码没有吞掉业务异常，只处理视口改变或再次导航导致的过渡取消。

## 三种样板的八维度复查

视觉参照继续沿用[上一批的来源与边界](style-signature-review.md#对照依据与边界)，不宣称获得外部评审认证。

| 维度 | 本轮结果 |
| --- | --- |
| Typography | Bauhaus 粗体轴线与紧凑标题；手绘保留倾斜笔迹与纸面正文；SYNTH-84 保留等宽仪表标题 |
| Whitespace | 放大主视觉、拉开正文和工作区间距；手绘桌面与手机分别重排导航和图文比例 |
| Visual hierarchy | 几何构成、花枝笔记、公路落日分别成为首屏焦点；画布、日记本、播放器延续同一视觉语言 |
| Color | 修正手绘浅橙色文字 CTA，对纸白底对比度 5.50:1；复古未来辅助文字对渐变三个停点均超过 6:1；包豪斯形状选中态与底色分开，红色按钮改黑字以满足正文对比度 |
| Motion | 站点、内容、弹窗与视口切换各自使用短过渡；三种样板保留自身的状态节奏 |
| Micro interaction | 几何选中和清空可见，笔记保存进入日记本，播放器暂停与播放有明确的亮度变化 |
| Responsive | 检查 1280、390、320px；三款默认、深色、形式模式均保留完整操作与可读内容 |
| Originality | 三幅主视觉为仓库内原创 SVG，替换通用小几何、渐变景观和柱状图；未引入第三方获奖网站素材 |

## 复查发现与修正

第一轮修正手绘 CTA 对比度、复古未来辅助文字对比度、包豪斯选中形状被同色背景吞掉的问题。手机端重排手绘搜索与导航，复古播放器三按钮保持单行。

动效实测修正了旧、新正文叠字、杂志样板原有展开动画吞掉关闭渐隐、备用导航覆盖后续同页锚点，以及 iframe 变宽时跨文档快照中断的问题。完整回归还发现公共 popover 的 display 过渡会短暂阻止 Tooltip 隐藏离屏浮层，已将这段样式限定到样板选择器，保留 Tooltip 原有的定位与隐藏逻辑。退出动画覆盖实际弹窗状态，等待动画结束后再释放焦点边界；测试不通过放宽错误断言来隐藏问题。
