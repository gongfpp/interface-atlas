## 动效与返回

以下记录是初次接入状态；后续 25 种组件材质、弹层开合与页面过渡修正见 [组件检查记录](atlas-component-audit.md)。

- 按钮：沿用各风格 `--motion`（80–400ms）；悬停提亮/上移，按下下压或内凹，释放恢复。像素使用阶梯时间函数。
- 弹层：调用既有 `atlas-runtime.ts` 的风格进入动画；关闭后回到原触发控件。前进/后退同步 URL 与弹层。减少动态效果时跳过动画。
- 页面：沿用已有页面进入 240ms、离开 180ms 的过渡定义；导航保持实际链接。
- 黏土：点击捏压，320ms 回弹，结束恢复原形；连续点击取消上一段动画。
- 极光/蒸汽波：开关启动慢速光场/图片移动，关闭停止；减少动态效果时不播放。
- 合成音：只在点击播放后创建声音；离开页面停止并释放，避免自动播放。

## 与图稿的差异及待验收项

摄影/插画复用项目已有素材；包豪斯用可编辑几何舞台替代图稿建筑，孟菲斯用 CSS 海报替代展厅摄影，企业孟菲斯插画人物不同。字体以现有字体和系统回退为准，像素标题目前为等宽字加阶梯阴影，并非图稿像素字库。液态透镜用 CSS 折射观感，不是物理光线模拟。

图稿错误的风格编号、虚构播放列表、视频时长和无实现依据的业务按钮未写入产品。卡带是装饰，没有假播放操作。像素画板沿用真实 8×8 实现。

仍需实机逐页核对构图、字体回退、比例、图片裁切、320px 溢出、弹层焦点和动效。未宣称已按图还原或通过视觉验收。
