## 第六轮复查

22:54–22:58 的本机浏览器失败记录显示，黏土深色输入框的焦点框仍是页面强调色。全局 `!important` 焦点规则现已把有独立焦点样式的风格控件排除，其他可聚焦元素继续沿用全局规则。

玻璃、便当盒等页的测试曾在打开菜单后等不到可点击的选项。菜单现在会在视口尺寸变化时重新定位。触发器在自动滚动期间暂时移出视口时，选项随它隐去并在返回时恢复。选中、移出焦点和外部点击仍能关闭菜单。

“查看案例”和画面中的探索入口现在打开已选变体，具名案例仍按各自的索引打开。关闭时焦点返回实际触发按钮，按键翻至最后一个案例后能继续向前翻页。复古网页的文件夹直接取自实际案例，根目录按钮在根目录中禁用。旧用例已按实际的角度显示和复选框元素更新。

本轮完成 364 项单元测试、341 个文件的 Astro 类型检查、Lint 和 500 页构建。检查了 50 个中英文风格页的案例入口、142 个带语言的案例链接、文件夹、资源和 ARIA 引用。另用模拟 DOM 执行了实际菜单代码的滚动、视口变化、选择与关闭回调。

本轮预览服务已能启动。Playwright 的 Chromium、WebKit 和 Firefox 均在打开页面之前启动失败，其中 Chromium 报 macOS Mach 服务注册权限被拒绝。上述历史浏览器失败仍需在最终版本上复测，菜单在真实滚动和动画过程中的表现待验收。改动仍在工作区，未提交或部署。
