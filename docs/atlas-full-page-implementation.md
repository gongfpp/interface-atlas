## 本次改变

`/styles/{slug}/` 和 `/en/styles/{slug}/` 现在直接渲染 `src/components/atlas/AtlasPage.astro`，不再在通用概念详情中嵌入 iframe。原 `/style-scenes/` 和 `/style-covers/` 示例仍保留，独立回归测试也保留。组件等非风格详情不改变页面结构。

25 种风格各有桌面网格、阅读顺序、排印、材质和控件样式。具体布局见 [atlas-implementation-manifest.json](atlas-implementation-manifest.json)。内容与控件的共同能力复用，风格布局不共享同一套首屏模板。标题、主视觉、变体、控制、阅读与提示词的位置分别定义；移动端恢复可读的顺序，不整体缩放桌面画布。

首页入口为固定导航左上角的图标＋文字，最小点击区域 88×44px；移动端保持显示。ResizeObserver 根据实际导航高度留出正文和锚点空间，滚到页脚仍保留入口。全部风格、语言、收藏、提示词与指南均有实际入口。

黏土、像素、赛博朋克、装饰艺术、Y2K、蒸汽波新增六张无文字的独立美术资产，存放在 `src/assets/atlas/`。其它视觉由已有摄影、CSS、SVG 组成。没有把效果稿整张作为页面或伪控件背景。

## 已编写的行为

- 变体选择同步页面视觉与默认提示词；手工编辑后保留文字，只有明确组合或恢复操作才覆盖。
- 项目名称校验、需求组合、可编辑输出、复制成功反馈与复制失败手动选择。
- 详情和指南使用原生 dialog，支持 Escape、关闭、焦点返回；详情前后切换有端点禁用。弹层使用浏览器历史，后退关闭、前进重开；快速关闭不会重复后退。
- 采用逐风格动效时长。粗野、瑞士、复古窗口、包豪斯硬切；便当从点击来源展开；糖果/黏土缩放；玻璃/手绘/拟物位移；像素离散帧。减少动态效果时停用动画。通用站点的统一按钮闪亮效果不再应用于这些页面。
- 包豪斯构图支持添加、撤销、重做、清空；像素画布支持颜色、键盘绘制、清空；手绘便笺可写入和清除；协作清单更新进度。
- 复古文件夹有独立前进后退、根目录和窗口折叠；该根目录与站点“首页”入口区分。
- 玻璃磨砂、液态透镜厚度、光谱、排印、留白、拼块间距等控制真实视觉属性；透镜跟随指针的范围有限，滑杆也可键盘操作。
- 合成器只在明确点击后播放本机合成音，离开页面或隐藏标签停止；光场漂移由显式开关控制。

以上是实现说明，不能替代浏览器运行证据。
