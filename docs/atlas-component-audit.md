# 25 种风格的组件修正

后续行为修正见 [风格交互修正](atlas-interaction-followup.md)：真实案例、字段错误、统一下拉、局部按压与备用跳转已继续接入；本文件记录上一轮组件外观改动。

用户反馈：部分风格页面的按钮、组件与动效没有使用对应风格。此轮依据已有整页设计板修正组件实现，覆盖全部 25 种风格的中英文路由。

## 确认的问题与修正

- 原滑杆、复选框主要依靠 `accent-color`，缺少材质、轮廓和选中状态。改为保留原生语义的自定义外观：轨道、滑块、勾选框、开关旋钮分别继承风格材质；滑杆填充随实际值更新。
- 输入框、下拉、弹层和收藏按钮被通用规则覆盖。补齐各风格边框、填充、内外阴影、字体、悬停、按下、选中、禁用与焦点；提示词、导航和弹层按钮使用同一套材质。
- 弹层 CSS 与 JS 同时播放进入动画，关闭统一淡出。现在由 JS 单独管理：按材质进入、沿对应方向收回，关闭中断进入时从当前姿态开始；返回仍恢复触发控件焦点。
- 案例弹层按序号强行改变边框宽度与对齐，破坏风格。移除这两项行内覆盖，保留实际变体内容与应用操作。
- 页面跳转原本主要改变时长。补齐纸页、扫描、抽屉、贴纸、回弹等过渡；仍使用真实链接与浏览器前进/后退。减少动态效果时关闭动画。
- 下拉箭头移到独立装饰层，避免覆盖手绘横线、金属或玻璃填充。支持 `appearance: base-select` 的浏览器同时渲染材质弹出菜单；其他浏览器保留原生选项弹窗，外框与字段仍使用风格材质。
