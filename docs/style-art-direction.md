# 25 种风格整页视觉与交互方案

本轮成果是图像生成的设计提案，覆盖整页、组件状态、移动端和动效关键帧；不是运行截图，也不是交互验收记录。先完成效果稿，再据稿开发。

## 使用顺序

1. 以当前会话最后一轮 25 张独立布局效果稿为依据，旧版共享右侧状态栏的设计板已被替代。不得复用同一首屏与区域排列，仅替换配色。
2. 本文件记录交互方向；style-art-direction.json 为旧轮生成输入，不再代表最新版构图。当前代码布局映射见 atlas-implementation-manifest.json，验证边界见 atlas-full-page-implementation.md。
3. 实现时逐项核对构图、字体字形与张力、字号比例、素材、材质、布局、组件状态及动效，不能只按颜色复刻。
4. 实机检查桌面、390px、320px及键盘/触屏；动画必须实际运行，图片中的关键帧不算验证通过。

## 所有风格共有的操作契约

- 风格卡进入对应整页；返回列表恢复筛选与滚动位置。浏览器前进后退使用真实历史语义，没有历史时前进/后退入口禁用。
- 页内章节跳转保持同一主滚动区域。页面导航、浮层、菜单和页脚全部继承该风格。
- 变体仅采用项目已有的同风格变体；其他风格不能冒充变体。选择后同步页面与提示词；不要自动清除用户输入，复位需显式操作。
- 按钮覆盖默认、悬停、按下、键盘焦点和禁用；复选框、单选框、开关、标签页和分页均有选中/未选中状态。
- 下拉框展示展开、选中、滚动和关闭；键盘方向键移动、Enter选择、Escape关闭，焦点返回触发器；不只设计收起外观。
- 输入区域有空值、填写、焦点、错误及修正结果。项目名称为空提示“请输入项目名称”；不凭空限制正常标点、不编造搜索数量或远程服务成功。
- 提示词由当前风格、实际变体和用户需求组合，可编辑。复制成功后显示短暂确认；复制失败提供手动选择文本。不能伪装调用真实 AI。
- 详情面板支持关闭、取消、上一项、下一项、Escape、焦点返回。首项和末项的不可用方向有禁用反馈；不意外循环。关闭后保留原阅读位置。
- 重置恢复当前风格默认参数；演示内容保持页面内存边界。收藏等原有站点能力遵守原契约，不能因风格改造消失。
- 移动端重排，而非缩小整张桌面；保留可读字体和触控范围。菜单、选项和浮层不超出屏幕。
- 动效必须定义触发、时长、结束、反向返回和中断。快速连续操作以最新操作为准，不叠加多个未结束动画；减少动态效果时取消背景漂移、缩放和位移，保留即时状态反馈。
- 图片里的图标、文案、字号数字和颜色值可能出现生成偏差，开发前与内容数据核对。图中出现的额外登录、语言、社交入口、未定义变体、作者署名或结果数字不构成新增功能授权。

## 本轮检查中发现的问题

- 第一轮极简：多余登录与多语言、其他风格混入变体。
- 第一轮瑞士：变体未采用现有分类，出现不需要的署名与输入限制。
- 第一轮杂志：变体混入其他风格，出现虚构数量、日期及不合适的输入错误示例。
- 第一轮复古互联网：关键帧画成缩放转场，与即时切换契约冲突。
- 第一轮扁平设计：缺失提示词编辑区，出现不应作为默认风格的阴影。
- 修订稿继续作为提案审阅；不得以“生成结束”替代可用性与实机验收。
